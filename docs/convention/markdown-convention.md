# Markdown 파일 컨벤션

- 파일명은 **무조건 영문**. 한글·공백·특수문자 금지.
- 형식: `kebab-case.md` (소문자, 단어는 `-`로 구분). 예: `api-design.md`, `meeting-notes-2026-10-12.md`
- 날짜가 들어가면 `YYYY-MM-DD` 형식으로 파일명 끝에 붙인다.
- 예외: 관례상 대문자인 파일은 그대로 둔다 — `README.md`, `CLAUDE.md`, `CHANGELOG.md`, `LICENSE.md`
- 본문 언어는 자유 (한글 가능). 규칙은 파일명에만 적용.
