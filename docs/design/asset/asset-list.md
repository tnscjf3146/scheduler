# 에셋 목록 (MVP)

만들어야 할 브랜드 에셋과 UI 아이콘 목록. 화면과 기능은 [기능 명세](../spec/feature-spec.md)와 [유저플로우](../user-flow/user-flow.md)를, 고정 값(우선순위·분류 등)은 [ERD 열거형](../erd.md#열거형)을 따른다.

- 대상: 웹(React)과 앱(Compose Multiplatform, Android 먼저)
- 우선순위: **P0** MVP 출시에 필요 / **P1** 있으면 좋음 / **P2** 다음 단계

## UI 아이콘

공통 규격: 24×24 그리드, 아웃라인 2px, SVG로 내보낸다. 웹은 SVG 컴포넌트, 앱은 Vector Drawable(`composeResources/drawable/`)로 넣는다.

- **도메인 아이콘**(이슈 유형, 우선순위, 상태 분류 등)은 서비스 성격이 드러나므로 **직접 디자인**한다.
- **일반 아이콘**(검색, 설정, 닫기 등)은 Material Symbols(Outlined)나 Lucide 같은 라이브러리를 쓰면 작업량이 크게 준다. 직접 그린다면 도메인 아이콘과 같은 규격으로 맞춘다.

### 도메인 아이콘 (직접 디자인)

#### 이슈 유형

기본 유형 5개. 카드·목록에서 작게(16px) 보이므로 **색 배경 배지 + 흰 아이콘** 형태도 함께 검토한다.

| 아이콘 | 우선순위 | 계층 | 메모 |
|---|---|---|---|
| 에픽 | P0 | `EPIC` | 번개·깃발 등 |
| 스토리 | P0 | `STANDARD` | 책갈피 등 |
| 작업 | P0 | `STANDARD` | 체크 박스 |
| 버그 | P0 | `STANDARD` | 벌레·점 |
| 하위 작업 | P0 | `SUBTASK` | 갈라지는 선 |
| 사용자 정의 유형용 아이콘 세트 | P1 | - | 관리자가 유형을 추가할 때 고르는 프리셋 (6~8개). MVP에서는 계층별 기본 아이콘을 써도 된다 |

## 일러스트 · 빈 화면 (P2)

| 에셋 | 쓰는 곳 |
|---|---|
| 프로젝트 없음 | 프로젝트 목록 첫 화면 |
| 진행 중 스프린트 없음 | 보드 ("백로그에서 스프린트를 시작하세요") |
| 검색 결과 없음 | 이슈 목록 |

- 일러스트를 미루는 동안에는 큰 UI 아이콘 + 문구로 대신한다.

## 작업 순서 (제안)

1. 메인 컬러와 로고 콘셉트를 정한다.
2. 로고 심볼 → 앱 아이콘·파비콘 (P0)
3. 도메인 아이콘: 이슈 유형 5개, 우선순위 5개, 스프린트 (P0)
4. 일반 아이콘 출처를 정하고 P0 일반 아이콘을 채운다.
5. P1 → P2 순서로 나머지
