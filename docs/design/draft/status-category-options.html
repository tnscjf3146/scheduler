상태 분류 표시 시안

상태는 유저가 만들지만 분류(할 일 · 진행 중 · 완료)는 3개로 고정이에요. 상태 이름이 늘어나도 지금 어느 단계인지 보이도록, 분류를 색 · 배지 · 보드 · 설정 화면에서 어떻게 보여줄지 고르는 시안이에요. 항목마다 20안 이상이고, 카드를 누르면 맨 아래 미리보기에 바로 반영돼요.

1. 분류 색

분류마다 색 하나. 같은 분류의 상태는 모두 같은 색을 써요. 흑백으로 바꿔 보면 색 없이도 구분되는지 확인할 수 있어요.

2. 상태 배지

이슈 목록 · 상세 · 검색 결과에 붙는 상태 표시. 왼쪽에서 채움 방식을, 오른쪽에서 분류 모양 아이콘을 따로 골라 조합해요. 예시 상태 7개: 할 일 · 백로그 / 진행 중 · 코드 리뷰 · QA / 완료 · 배포됨.

채움 방식

배경 · 테두리 · 모서리 · 글자 굵기. 오른쪽에서 고른 모양이 함께 들어가요.

모양 아이콘

분류를 모양으로도 구분해서 색이 안 보여도 단계가 읽혀요. 왼쪽에서 고른 채움 방식으로 보여줘요.

3. 보드에서 분류 보여주기

보드는 상태 1개 = 열 1개. 열이 많아져도 단계가 읽히도록 열 · 열 머리 · 카드에 분류를 표시하는 방법이에요. 작게 줄여 보여주니 미리보기에서 크게 확인하세요.

4. 설정 › 상태 화면

관리자가 상태를 추가 · 정렬 · 삭제하는 화면. 정책: 분류 3개 고정, 분류마다 상태 1개 이상, 만든 뒤 분류 변경 불가.
