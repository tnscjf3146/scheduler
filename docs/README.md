# docs

Jira 비슷한 이슈 트래커 기획/설계 문서.

## 폴더 구조

```
docs/
├── README.md
├── analysis/          # Jira 분석 (구조)
├── convention/        # 컨벤션
├── setup/             # 기술 스택, 개발 환경 세팅
└── design/            # 설계
    ├── erd.md         # ERD (데이터 모델)
    ├── asset/         # 에셋 목록 (로고, 아이콘)
    ├── draft/         # 디자인 시안 (HTML, 브라우저로 열기)
    ├── spec/          # 명세
    ├── user-flow/     # 유저플로우
    └── policy/        # 정책
```

| 폴더 | 내용 |
|------|------|
| `analysis/` | Jira 구조 분석 |
| `convention/` | 컨벤션 (코드, 커밋, 브랜치 등) |
| `setup/` | 기술 스택 특징, 프론트엔드 · 백엔드 · 앱 세팅 방법 |
| `design/erd.md` | ERD (데이터 모델) |
| `design/spec/` | 기능 명세 |
| `design/user-flow/` | 유저플로우 |
| `design/policy/` | 정책 |
| `design/asset/` | 에셋 목록 (로고, 앱 아이콘, UI 아이콘) |
| `design/draft/` | 디자인 시안. `issue-icon-options.html`: 이슈 유형 · 우선순위 아이콘 시안, `status-category-options.html`: 상태 분류(할 일 · 진행 중 · 완료) 표시 시안 |
