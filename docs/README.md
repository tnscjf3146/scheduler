# docs

Jira 비슷한 이슈 트래커 기획/설계 문서.

## 폴더 구조

```
docs/
├── README.md
├── analysis/          # Jira 분석 (구조)
├── convention/        # 컨벤션
└── design/            # 설계
    ├── erd.md         # ERD (데이터 모델)
    ├── spec/          # 명세
    ├── user-flow/     # 유저플로우
    └── policy/        # 정책
```

| 폴더 | 내용 |
|------|------|
| `analysis/` | Jira 구조 분석 |
| `convention/` | 컨벤션 (코드, 커밋, 브랜치 등) |
| `design/erd.md` | ERD (데이터 모델) |
| `design/spec/` | 기능 명세 |
| `design/user-flow/` | 유저플로우 |
| `design/policy/` | 정책 |
