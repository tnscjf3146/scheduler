# API

프론트(React)가 백엔드(FastAPI)에 보내는 요청 목록. 데이터는 [ERD](erd.md)를 따른다.

요청·응답의 자세한 형식은 따로 쓰지 않는다. FastAPI가 코드에서 자동으로 만드는 문서(`/docs`)를 본다. 이 문서에는 어떤 API가 필요한지 목록만 둔다.

## 공통

- 기본 경로: `/api`
- 요청·응답 본문은 JSON
