# 스킬 & 하네스 기능 보고

| 항목 | 값 |
| --- | --- |
| 날짜 | 2026-11-25 |
| 브랜치 | `feature/mvp` |
| 검증 | 백엔드 테스트 21개 통과, 화면 확인, Claude Code 실제 실행 1회 |

## 1. 결론

Agent 위젯에 "스킬 & 하네스" 탭을 추가했다. 사용자는 이 탭에서 스킬과 하네스를 만들고, 이미 가진 것을 가져오고, 에이전트에 적용한다.
AI 에이전트는 새 MCP 도구로 스킬, 하네스, 에이전트를 만들 수 있다. 하지만 에이전트에 적용하는 일은 사용자만 한다.
적용한 스킬과 하네스는 Claude Code 에이전트에만 들어간다. Codex에는 같은 장치가 없기 때문이다.

## 2. 용어

- **스킬**: Claude Code가 필요할 때 읽는 지시 묶음이다. 이름, "언제 쓰는지" 설명, 마크다운 본문으로 이루어진다.
- **하네스**: 이 앱에서는 Claude Code 훅(hook)을 뜻한다. 훅은 정해진 시점에 명령을 자동으로 실행한다. 예를 들어 "도구 실행 전"에 명령을 실행할 수 있다.
- **플러그인**: 스킬과 훅을 한 폴더에 묶은 Claude Code의 확장 형식이다. `claude --plugin-dir <폴더>`로 불러온다.

## 3. 사용자가 할 수 있는 일

| 기능 | 위치 | 동작 |
| --- | --- | --- |
| 목록 보기 | Agent 위젯 › 스킬 & 하네스 탭 | 스킬과 하네스를 종류, 이름, 설명, 적용한 에이전트 수와 함께 보여 준다 |
| 만들기 | 탭의 "+ 만들기" | 스킬 또는 하네스를 고르고 내용을 쓴다. 오른쪽에서 적용할 에이전트를 고른다 |
| 가져오기 | 탭의 "가져오기" | 내가 가진 스킬과 하네스를 앱에 복사한다(4장) |
| 고치기·지우기 | 목록의 항목 클릭 | 내용과 적용할 에이전트를 바꾼다. 지우면 붙어 있던 에이전트에서도 빠진다 |
| 에이전트 추가 시 적용 | Agent 탭 › + 추가 | 폼 아래의 "스킬 & 하네스" 체크박스로 고른다 |

입력 칸은 종류마다 다르다.

- 스킬: 이름, 언제 쓰는지, 내용(마크다운)
- 하네스: 이름, 실행 시점, 대상 도구, 실행할 명령, 설명

실행 시점은 9가지 중에서 고른다. 예를 들어 도구 실행 전, 도구 실행 후, 요청을 보낼 때, 응답을 마쳤을 때가 있다.
대상 도구는 "도구 실행 전·후"에만 쓴다. 예를 들어 `Bash`나 `Edit|Write`처럼 쓴다.

바뀐 내용은 에이전트를 재시작하면 들어간다. 에이전트가 시작할 때마다 플러그인을 새로 만들기 때문이다.

## 4. 가져오기

가져오기 화면은 다음 두 곳을 읽는다.

1. `~/.claude/skills` 아래의 `SKILL.md`. 네 단계 깊이까지만 찾는다.
2. `~/.claude/settings.json`의 `hooks`

이 두 곳의 스킬과 훅은 이미 이 사용자의 모든 Claude Code 세션에 적용된다. 에이전트도 마찬가지다.
그래서 가져오기는 원본을 옮기지 않고 앱에 사본을 만든다. 사본은 고칠 수 있고, 원하는 에이전트에만 붙일 수 있다.

## 5. MCP 도구 (에이전트용)

에이전트가 쓰는 `scheduler` MCP 서버에 도구 5개를 더했다. 전체 도구는 12개가 되었다. 전체 목록과 입력값은 [`mcp-tools.md`](./mcp-tools.md)에 있다.

| 도구 | 하는 일 |
| --- | --- |
| `create_skill` | 스킬을 만들어 "스킬 & 하네스" 목록에 넣는다 |
| `create_hook` | 하네스를 만들어 목록에 넣는다 |
| `list_extensions` | 스킬과 하네스, 붙은 에이전트를 본다 |
| `create_agent` | 에이전트를 만든다. CLI는 `claude`나 `codex`만 고를 수 있다 |
| `list_agents` | 에이전트 목록을 본다 |

AI가 스킬을 만들 때 따르는 규칙은 기본 스킬 `skill-writing-rules`에 있다. 이 스킬은 앱을 처음 켤 때 목록에 한 번 들어가고, 사용자가 고치거나 지울 수 있다.

- 이름은 영어 소문자·숫자·하이픈으로 쓴다.
- 설명과 내용은 한국어로 쓴다. 영어 단어(용어, 제품 이름, 명령, 코드)는 그대로 두고, 영어로만 이루어진 문장만 한국어로 바꾼다.

이 규칙은 코드로 막지 않는다. `create_skill` 도구 설명이 "만들기 전에 이 스킬을 읽고 따른다"고 시킬 뿐이다. 그래서 AI가 규칙을 어길 수 있다. 이름이 어긋나면 앱이 에이전트에 넘길 때 `skill-<번호>`로 바꾼다.

에이전트가 만든 항목에는 "○○이(가) 만듦 · 검토 필요" 표시가 붙는다. 사용자가 그 항목을 열어 저장하면 표시가 사라진다.

### 에이전트에게 적용 권한을 주지 않은 이유

- 에이전트는 스킬과 하네스를 에이전트에 붙일 수 없다. 이 일을 하는 MCP 도구가 없다.
- `create_agent`로 만든 에이전트에도 스킬과 하네스를 붙일 수 없다.

하네스는 CLI가 묻지 않고 명령을 실행한다. 그래서 에이전트가 하네스를 만들어 자기에게 붙일 수 있으면, CLI의 명령 실행 확인을 건너뛸 수 있다.
이 경로를 막으려고 적용은 사용자가 화면에서만 하게 했다.

## 6. 동작 구조

```
[사용자 / 에이전트(MCP)] ─만들기─▶ extensions 표 (SQLite)
                                        │
[사용자] ─적용─▶ agents.extensions (붙인 항목 id 목록)
                                        │
에이전트 시작 (sessions._launch_script)
   └─ extensions.build_plugin(agent)
        └─ %APPDATA%\Scheduler\agents\<id>\plugin\
             ├─ .claude-plugin\plugin.json
             ├─ skills\<이름>\SKILL.md
             └─ hooks\hooks.json
   └─ claude --mcp-config ... --plugin-dir <위 폴더>
```

- 플러그인은 앱의 에이전트 폴더에 만든다. 에이전트의 작업 폴더에는 아무것도 쓰지 않는다. 작업 폴더가 사용자의 프로젝트일 수 있기 때문이다.
- 플러그인은 시작할 때마다 지우고 새로 만든다. 그래서 빼거나 지운 항목은 다음 시작부터 사라진다.
- 붙인 항목이 없으면 플러그인을 만들지 않고 `--plugin-dir`도 넘기지 않는다.
- 스킬 이름은 영문 소문자, 숫자, 하이픈만 쓸 수 있다. 그래서 한글 이름은 `skill-<id 앞 8자>`로 바꾸고, 원래 이름은 설명 앞에 붙인다.

## 8. 검증

1. 백엔드 테스트 21개가 통과했다. 새 테스트는 다음을 확인한다.
   - `~/.claude`에서 스킬과 훅을 찾는다.
   - 에이전트가 MCP로 하네스와 에이전트를 만든다.
   - 사용자가 적용하면 시작 명령에 `--plugin-dir`가 들어가고, 플러그인 안에 스킬 파일과 `hooks.json`이 생긴다.
   - 지우면 플러그인이 사라진다.
2. `claude plugin validate`로 만든 플러그인을 검사했고 통과했다. 경고는 README, 라이선스, 아이콘이 없다는 것뿐이다. 이 경고는 플러그인 디렉터리에 공개할 때만 필요한 항목이다.
3. Claude Code를 실제로 한 번 실행했다. 스킬과 훅을 하나씩 넣은 플러그인을 `--plugin-dir`로 넘겼다.
   - 스킬에만 적힌 비밀 단어를 물었고, Claude가 그 단어로 답했다.
   - "요청을 보낼 때" 훅이 표시 파일을 만들었다.
4. 테스트용 서버와 Chrome으로 탭, 가져오기, 편집 창, 에이전트 추가 폼을 찍어 확인했다.

## 9. 한계와 남은 일

- **Codex 에이전트에는 적용되지 않는다.** 화면에서 Codex 에이전트는 체크박스가 꺼져 있다.
- **가져온 스킬은 `SKILL.md`만 복사한다.** 스킬 폴더의 다른 파일(스크립트, 참고 문서)은 따라오지 않는다. 그래서 그런 파일을 쓰는 스킬은 가져온 뒤 일부가 동작하지 않을 수 있다.
- **같은 스킬이 두 번 들어갈 수 있다.** `~/.claude`의 스킬은 이미 모든 에이전트에 들어간다. 그래서 그것을 가져와 붙이면 같은 내용이 두 번 들어간다.
- **이미 만든 에이전트의 적용 목록은 스킬·하네스 편집 창에서만 바꾼다.** 에이전트 메뉴에는 이 기능이 없다.
- **기존 에이전트의 `AGENTS.md`에는 새 도구 설명이 없다.** `AGENTS.md`는 에이전트를 처음 만들 때와 인수인계할 때만 쓰기 때문이다. 도구 자체는 MCP에서 바로 받아 오므로 쓸 수 있다.
- 하네스 명령이 Windows에서 어떤 셸로 실행되는지는 Claude Code가 정한다. 실제 실행에서 `python -c ...` 명령은 동작했다.
